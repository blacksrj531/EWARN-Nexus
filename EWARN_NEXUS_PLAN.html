1 Core Architectural Capabilities

🎥

Simultaneous Multi-Camera Ingest

Break free from traditional single-camera meeting restrictions.

  • Integrated Webcam: Primary high-resolution face/speaker stream.
  • External USB Camera(s): Secondary angle for workbench, document view, or wide room inspection.
  • Independent Controls: Mute, toggle, or swap individual camera feeds without disrupting the meeting.
  • Adaptive Grid: Clean layout resizing automatically whether a user has 1, 2, or 4 active feeds.
📡

Local IP Camera & RTSP Integration

Integrate CCTV, workshop, or site cameras directly into the call.

  • Direct Network Stream: Connect to HTTP/MJPEG streams from Hikvision, CP Plus, Dahua, and ONVIF cameras.
  • WebRTC Canvas Relay: Relays local network cameras through the browser to remote participants on mobile or remote internet.
  • Virtual Camera Bridge: Native support for OBS / VLC virtual camera feeds.
  • 1-Click Inclusion: Add and label site feeds (e.g., "Site Gate Cam 01").
💬

Dual-Layer Chat System

Real-time messaging engineered for operational clarity and privacy.

  • Public Room Chat: General room-wide announcements visible to all connected participants.
  • Private 1-on-1 Chat: Dedicated encrypted peer channel between any two specific participants.
  • Delivery Indicators & Timestamps: Clean timestamps and unread message indicators.
🔒

Zero-Storage P2P File Sharing

Enterprise-grade file transfer without recurring cloud storage fees.

  • True Direct Peer-to-Peer: Files transfer directly from browser memory to browser memory.
  • Zero Cloud Stored Files: Zero compliance risk or third-party storage fees.
  • Real-Time Transfer Progress: Instant chunk-by-chunk progress bars with automatic download on completion.

3 Participant Experience & Latency Profile

🚀

Frictionless 1-Click Joining

No downloads, no installations, zero login barriers.

  • Host Generates Link: Cryptographically secure room URL generated instantly with 1 click.
  • Zero Installation: Participants join directly from any browser (Chrome, Edge, Safari) on laptops, tablets, or phones.
  • Hardware Agility: Seamless support for users with only 1 laptop webcam, or those plugging in secondary USB cameras.
  • IP Camera Modular Ready: IP camera ingest stays ready on demand without interfering with standard calls.
⚡

Ultra-Low Latency (WebRTC vs GitHub)

Decoupled Control-Plane & Peer-to-Peer Data-Plane.

  • GitHub Role: Only loads the web page once in <1 second via its global CDN, then steps out completely.
  • Direct Media Stream: Video & audio travel directly device-to-device with zero server detour.
  • Latency Benchmarks: Domestic calls 50ms – 150ms; International 150ms – 250ms.
  • Max-Speed File Transfers: Transfers at the true speed of your internet, free from cloud storage throttles.
